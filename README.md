# Agent Operations — เข้าสู่ระบบปกติแบบไม่บังคับ Authenticator

รุ่น 2.3.0-app-scoped-login / REAL ONLY

## สถานะ
แก้ไฟล์และทดสอบในเครื่องแล้ว **ยังไม่ได้ deploy เว็บไซต์หรือรัน SQL บน Supabase**
GitHub connector รายงาน `push: false` และ Supabase connector ในรอบนี้ไม่มี execute_sql หรือคำสั่งแก้บัญชี/สิทธิ์ จึงไม่พยายามข้ามข้อจำกัดเหล่านี้

## สิ่งที่แก้
การเข้าสู่ Agent Operations ปกติใช้ Email + Password หรือ Google ที่ผูกกับบัญชีเดิม แล้วตรวจผู้ใช้จริงจาก Supabase Auth `/user` และตรวจสิทธิ์ Workspace ผ่าน RPC/RLS ตามเดิม

ลบเงื่อนไขเฉพาะหน้าเว็บที่เรียก MFA ทุกครั้งเพียงเพราะบัญชีมี factor จากแอปอื่น ไม่ลบ MFA ของบัญชี ไม่เปลี่ยนรหัสผ่าน ไม่เปลี่ยน HR/DL Exam ไม่ปลอมระดับ `aal2` และไม่ใช้ service key ในหน้าเว็บ หากเซิร์ฟเวอร์ยังปฏิเสธด้วยข้อกำหนด AAL2 หน้าเว็บจะเคารพการปฏิเสธนั้น ไม่ลองข้ามด้วยสิทธิ์อื่น

Email ที่กรอกอย่างเดียวไม่ให้สิทธิ์ ต้องมีรหัสผ่านที่ถูกต้องหรือผ่าน Google และต้องเป็นบัญชีอีเมลที่ยืนยันแล้ว ไม่มีการสมัครสมาชิกหรือเพิ่มสิทธิ์จากหน้าเว็บอัตโนมัติ

การป้องกันการเข้าสู่ Agent Operations ลดเหลือการยืนยันชั้นแรกตามคำขอ ผู้ที่ได้รหัสผ่านหรือควบคุมบัญชี Google ของสมาชิกได้อาจเข้าถึงสิทธิ์ Agent Operations ของสมาชิกนั้นได้ จึงควรใช้รหัสผ่านใหม่ที่แข็งแรงและไม่ใช้รหัสที่เปิดเผยในแชท

## ทำให้ใช้งานบนเว็บจริง — ต้องทำทั้งสองข้อ

### 1. เปลี่ยนไฟล์หน้าเว็บ
นำเฉพาะ `index.html` จากชุดนี้ไปแทนไฟล์รากใน repository เดิม:
https://github.com/Ai-TeamSPU/Agent-Operations/upload/main

เมื่อ GitHub Pages deploy เสร็จ เปิด https://ai-teamspu.github.io/Agent-Operations/ แล้วกด Ctrl + Shift + R ท้ายหน้าต้องแสดง `V2.3`

### 2. ให้สิทธิ์ผู้ดูแลบัญชีที่เลือกไว้
เปิดไฟล์ `enable-workspace-admin.sql` คัดลอกทั้งหมด แล้ววางใน SQL Editor ของโครงการเดิม:
https://supabase.com/dashboard/project/doxunxbgqmybyckczucg/sql/new

รันด้วยบัญชีผู้ดูแลโครงการที่ได้รับอนุญาตครั้งเดียว สคริปต์ตรวจทั้งอีเมล ID ผู้ใช้ การยืนยันอีเมล และ ID Workspace ก่อนเพิ่มสมาชิก `datateam.gpt@spu.ac.th` เป็น `admin` เฉพาะ `agent-factory`

สคริปต์ไม่ให้สิทธิ์ `ai.teamspu@gmail.com` ไม่สร้างผู้ใช้ ไม่เปลี่ยน membership เดิมที่มีบทบาทอื่นหรือถูกระงับ และไม่เปลี่ยน RLS/MFA/รหัสผ่าน/ข้อมูล HR/DL Exam/Agent/Skill/RUN_LOG

ผลสำเร็จต้องแสดง `datateam.gpt@spu.ac.th | agent-factory | admin | true` หากข้อมูลผู้ใช้หรือ Workspace ไม่ตรง สคริปต์จะหยุดและไม่เพิ่มข้อมูล อย่าแก้ ID เพื่อฝืนให้ผ่าน

จากนั้นเข้าสู่ระบบด้วยบัญชีดังกล่าวผ่านรหัสผ่านที่ถูกต้อง หรือ Google ที่เคยผูกไว้ ไม่ต้องรีเซ็ตรหัสเพื่อใช้การแก้นี้ หากอ่านข้อมูลสำเร็จแต่ยังไม่มี Agent/งานที่ยืนยันแล้ว หน้าเว็บจะแสดงข้อมูลว่าง ไม่สร้างตัวเลขทดแทน

## สิ่งที่ไม่เปลี่ยน
การ **เปลี่ยนรหัสผ่าน/กู้คืนบัญชี** เป็นการแก้บัญชีร่วมของโครงการ ไม่ใช่การเข้าดู Agent Operations ตามปกติ จึงยังคงกระบวนการ MFA เดิมสำหรับการกู้คืนบัญชีที่เปิด MFA ไว้ การแก้นี้ไม่รับรองว่าจะทำให้การกู้คืนบัญชีที่ขาดอุปกรณ์สำเร็จ ใช้ Google สำหรับการเข้าแอปตามปกติได้เมื่อบัญชีผูกไว้และผู้ให้บริการยืนยันตัวตนสำเร็จ

Google อาจขอการยืนยันของ Google เอง การแก้นี้ไม่ได้ปิดการป้องกันของ Google

ไม่เปลี่ยน Site URL กลางของ HR Hub หากใช้ Google ให้คง Redirect URL ที่อนุญาตกลับมาที่ `https://ai-teamspu.github.io/Agent-Operations/` ตามที่ตั้งไว้เดิม

## ผลตรวจ
ฐานต้นฉบับเทียบกับ GitHub blob `94efe967a9c32090481a5df62a04616195a8896a` ก่อนแก้

Node syntax check ผ่าน และทดสอบ DOM / Auth contract แบบออฟไลน์ผ่าน 35 ข้อ ครอบคลุมล็อกอินที่มี factor เดิม การปฏิเสธจากเซิร์ฟเวอร์ รหัสผิด เซสชันใช้ไม่ได้ อีเมลไม่ยืนยัน ผู้ใช้ anonymous บทบาท viewer การล้างรหัส/เซสชัน Google callback แบบทดสอบ การคง MFA สำหรับการกู้คืน และหน้าจอ 390px

เบราว์เซอร์ในสภาพแวดล้อมนี้ไม่อนุญาตการนำทาง จึงใช้ DOM ในหน่วยความจำและแทน transport / location / storage / digest ในชุดทดสอบเท่านั้น ไม่ได้ใช้โค้ดแทนบริการเหล่านี้ใน index.html ที่ส่งมอบ ไม่ได้ล็อกอินบัญชีจริง ไม่ส่งอีเมล ไม่ส่งคำขอ Google จริง และไม่เขียนฐานข้อมูล

ดู `verification.json` และ `tests/test_login_dom.py` สำหรับขอบเขตการทดสอบ ไม่ใช่ใบรับรองว่าการตั้งค่าเซิร์ฟเวอร์ที่ใช้งานจริงผ่านทั้งหมดแล้ว

## การเก็บข้อมูล
คงข้อมูลจริงเท่านั้น ไม่มี demo registry, RUN_LOG จำลอง หรือประวัติที่แต่งขึ้นในไฟล์หน้าเว็บ ข้อมูลหลักและเซสชันไม่เก็บใน localStorage

ไม่ต้องอัปโหลด SQL, รายงาน, หรือชุดทดสอบขึ้น repository สาธารณะเพื่อให้เว็บไซต์ทำงาน
